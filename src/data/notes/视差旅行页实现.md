## 这一页是由六层叠出来的

整页是 `position: fixed` 的满屏舞台（`.explorescape`），里面**六个图层**按 z-index 从后往前叠。做的时候不用一次想清楚整页，**每层只解决一件事**，调的时候也只动那一层。

| 顺序 | 图层 | 干什么 | 怎么实现 |
|---|---|---|---|
| 1 | `.wallpaper-bg` | 底图 | 一张 `xiaguang.webp` |
| 2 | `PetalEffect` | 花瓣 | 复用首页那个组件 |
| 3 | `.light-beams` | 体积光 | `<canvas>` + `requestAnimationFrame` |
| 4 | `.falling-leaves` | 落叶 | 4 个绝对定位的 div |
| 5 | `.curtain` | 帘布 | 两张叶子图，左右滑走 |
| 6 | `.cover-content` | 标题区 | 打字 + 光斑 |

顺序不是随便排的：**帘布要盖住底下的所有东西**（它是"幕布"），而**标题要盖在帘布之上**（帘布拉开后露出来）。所以帘布在前、内容在后。

## 帘布：先合上，再拉开

一进来是"合着"的，800ms 后自动拉开：

```js
const curtainOpen = ref(false)
onMounted(() => {
  setTimeout(() => { curtainOpen.value = true }, 800)
  setTimeout(() => startTyping(), 1800)   // 等帘布开完再打字
})
```

帘布是**两张叶子图**，用 `translateX` 往两边滑走：

```css
.curtain.open .leaf-front { transform: translateX(-102%) }   /* z-index: 12 */
.curtain.open .leaf-back  { transform: translateX(102%) }    /* z-index: 11 */
```

两个细节：

- **102% 不是 100%** —— 留 2% 余量，免得边缘有 1px 没滑干净露出一条缝
- **前后两层错开**（12 / 11），滑的时候有前后景的层次感，而不是一张图对折

### 图片换成 WebP

原来用 `Anime-style green leaf composition.png` + `.jpeg`，两张加起来 **11.3MB**。转成 WebP 之后 **0.48MB**（左 0.28 + 右 0.20），**省 96%**。

插画/照片这类图用 WebP 收益就是这么大，`png` 基本只该用在需要无损的小图标上。

### 关掉再自动打开

右下角有个 `✕`，点了帘布合上 —— 但**不是结束，是循环**：

```js
function closeCurtain() {
  curtainOpen.value = false
  setTimeout(() => { typedLine1.value = ''; typedLine2.value = '' }, 400)  // 帘布开始合时清字
  setTimeout(() => {
    curtainOpen.value = true
    setTimeout(() => startTyping(), 600)   // 帘布到位后再打字
  }, 3000)
}
```

时间点要对齐：**清字要在帘布刚合上的瞬间**（合上了还留着字就很怪），**重新打字要等帘布开到位置之后**。所以是 400ms 清、3000ms 开、600ms 后打字 —— 三个时间点各管一段。

## Canvas 体积光

不用任何库，两个函数：**造噪声** + **画光束**。

### 噪声：用 sin 假装随机

体积光的"呼吸感"来自噪声 —— 每条光束的亮度随时间随机起伏，但不能真的随机（会闪）。做法是用一个 sin 哈希造一张固定长度的噪声表：

```js
function createNoiseData(size = 512) {
  const data = new Float32Array(size)
  for (let i = 0; i < size; i++) {
    let val = 0, amp = 1, freq = 1, maxVal = 0
    for (let o = 0; o < 4; o++) {              // 4 个倍频叠加
      const idx = Math.floor((i * freq) % size)
      const h = ((Math.sin(idx * 127.1 + 311.7) * 43758.5453) % 1 + 1) / 2
      val += h * amp
      maxVal += amp
      amp *= 0.5        // 每个倍频振幅减半
      freq *= 2.3       // 频率翻倍多
    }
    data[i] = val / maxVal
  }
  return data
}
```

**4 个倍频叠加**是关键：单个 sin 太规律，叠 4 层之后才有自然的"颗粒感"。振幅每层减半、频率每层翻倍，这是分形噪声的标准做法。

### 光束：一束拆成三段

光源在左上角（`w * 0.20`, `h * 0.05`），射出 80 条，铺开 `π * 0.62` 的角度：

```js
const segs = [
  { d1: radius,          d2: maxDist * 0.40, aMul: 2.0 },  // 近端，最亮
  { d1: maxDist * 0.40,  d2: maxDist * 0.70, aMul: 0.9 },  // 中段
  { d1: maxDist * 0.70,  d2: maxDist * 0.95, aMul: 0.25 }, // 远端，很淡
]
```

**每束光拆成三段、透明度递减**，比"一条等宽的线"自然得多 —— 真实的光束就是从窗口越照越淡、越照越散。颜色也跟着距离从暖白偏到偏黄：

```js
const g = Math.floor(252 - distRatio * 32)
const b = Math.floor(220 - distRatio * 55)
```

另外两个工程细节：

- **DPR 封顶 2** —— `Math.min(devicePixelRatio || 1, 2)`。4K 屏的 DPR 可能到 3，画布会大到掉帧，封在 2 视觉上看不出差别
- **卸载时 `cancelAnimationFrame`** —— 这个循环每秒跑 60 次，忘了取消的话切走页面还在烧 CPU

## 打字浮现

两行副标题逐字打出来：

```js
async function startTyping() {
  cursorLine.value = 1
  await typeLine(fullLine1, typedLine1, 80)
  cursorLine.value = 2
  await typeLine(fullLine2, typedLine2, 65)
  cursorLine.value = 0          // 打完光标消失
}
```

用 `setInterval` 逐字 `slice`，**包一层 Promise** 才能 `await` 出顺序 —— 否则两行会同时开始打。

`cursorLine` 记着"现在该哪个光标闪"，`0` 表示都打完了。

## 可拖动光斑

四句话飘在标题区，**能用鼠标或手指拖走**：

```js
spots: [{ x: -140, y: -8 }, { x: 160, y: 20 }, ...]
// 定位用 calc(50% + x)，所以以标题中心为原点，左右大致对称
left: `calc(50% + ${s.x}px)`
```

拖动分三步：`mousedown` 记下**鼠标起点**和**元素起点**，`mousemove` 算差值加上去，`mouseup` 收工。

```js
dragStart.value = { x: clientX, y: clientY, elX: el.x, elY: el.y }
// 移动时
x: dragStart.value.elX + (clientX - dragStart.value.x)
```

**必须同时记两个起点**：只记鼠标位置的话，元素会在按下的瞬间跳到鼠标那里；记下"元素原本在哪"，拖动才是"跟着鼠标的相对位移走"。

移动端要配 `touchstart` / `touchmove` / `touchend`，且 `touchmove` 上要 `preventDefault()` —— 不然拖光斑会变成滚页面。

每个光斑随机分到四套配色之一（`mint` / `pink` / `blue` / `iris`），视觉上不单调。

## 落叶粒子

4 片叶子，每片的参数都是随机的：

| 参数 | 范围 |
|---|---|
| 生命期 | 14–24s |
| 尺寸 | 4–10px |
| 左右摆幅 | 8–23px |
| 旋转量 | 8–23° |
| 透明度 | 0.12–0.32 |
| 模糊 | 0.5px / 1.5px 随机 |

**模糊和透明度是"景深"的来源** —— 同样的叶子，清晰的那片看着近、模糊的那片看着远，一层平面就有了纵深。

颜色用 5 档半透明绿随机取，模拟壁纸里那种稀疏的绿叶。

## 标题：点一下换个颜色

标题不是死的，点一下换一个绿：

```js
const greens = ['#2d5a27', '#3d6b35', '#1e4028', '#4a7c3f', '#2a5030']
```

换色时同时加一个 `.flash` 类，300ms 后去掉 —— 用 `brightness(1.6)` 闪一下作为点击反馈。**换色本身在深色背景上不够明显，加个亮度闪烁才"看得见点到了"**。

## 参数速查

| 想调什么 | 在哪 |
|---|---|
| 帘布拉开时机 | `onMounted` 里的 `setTimeout(…, 800)` |
| 打字开始时机 | 同上的 `1800` |
| 打字速度 | `typeLine(…, 80)` / `(…, 65)`（毫秒/字） |
| 关帘后重开的间隔 | `closeCurtain` 里的 `3000` |
| 光束数量 / 铺开角度 | `numRays = 80` / `spreadAngle = Math.PI * 0.62` |
| 光源位置 | `cx = w * 0.20` / `cy = h * 0.05` |
| 落叶数量 | `const count = 4` |
| 标题配色 | `greens` 数组 |

## 小结

这一页没有用任何动画库，四样东西各管各的：

- **帘布**用 `transform` 位移（GPU 合成，不触发重排）
- **体积光**用 Canvas 手画，`requestAnimationFrame` 驱动
- **打字 / 光斑 / 落叶**都是普通 DOM，改属性或类名

拆开看每个都不复杂。**难的是"什么时候发生"** —— 帘布开完才打字、帘布合上就清字、重新打开再打一遍，这些时间点对不齐，页面就会显得乱。
